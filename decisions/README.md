# Decision records

Decision records capture durable choices that are too specific for a principle and too small or settled for an RFC. A record should state the context, decision, alternatives, consequences, and affected documents. Decisions do not override normative specifications; when a decision changes a contract, it must be paired with an accepted RFC.
