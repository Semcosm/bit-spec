# Bit 规范

Bit 是一种小型、可移植的系统语言，以及它所对应的可验证中间表示（BIR）。

本网站按契约组织规范内容：

- [语言](spec/bit/language.md)：语法、语义、类型、内存、并发与模块。
- [BIR](spec/bir/overview.md)：类型化的中间表示与验证器契约。
- [架构](architecture/overview.md)：编译阶段、层次和信任边界。
- [设计](design/goals.md)：目标、原则、不变量和约束。
- [指南](guides/overview.md)：编译器、BIR 与引导实现的实践说明。

仓库目前是工作草案。文档的规范状态和变更治理方式请参阅 [RFC 流程](rfcs/0000-rfc-process.md)。

规范正文当前以英文作为唯一事实来源；中文页面提供导航和项目概览，翻译内容会在经过评审后逐步加入。
