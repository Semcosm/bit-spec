# Bit Specification

Bit is a small, portable systems language and its verified intermediate representation (BIR).

Use the sections below to navigate the specification:

- [Language](spec/bit/language.md) - syntax, semantics, types, memory, concurrency, and modules.
- [BIR](spec/bir/overview.md) - the typed intermediate representation and verifier contract.
- [Architecture](architecture/overview.md) - compilation stages, layers, and trust boundaries.
- [Design](design/goals.md) - goals, principles, invariants, and constraints.
- [Guides](guides/overview.md) - practical guidance for compiler, BIR, and bootstrap work.

The repository is a working draft. Normative status and change governance are described in the [RFC process](rfcs/0000-rfc-process.md).
