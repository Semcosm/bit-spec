# Guide overview

These guides explain how to work with the specification. They are informative and cannot override a normative rule under `spec/`.

- [Compiler guide](compiler.md) follows a source module through the pipeline.
- [BIR guide](bir.md) explains how to inspect and verify an IR module.
- [Bootstrap guide](bootstrap.md) describes the minimum path to a reproducible seed toolchain.

When a guide and a specification appear to disagree, report the guide as a documentation bug and follow the specification until the discrepancy is resolved.
